# Spam Text Classification using Deep Learning

This project implements a spam text classification model using deep learning model. The model is designed to classify text messages as either "spam" or "ham" (not spam) based on their content.
This repo contains the data, requirements file and the notebook for creating the model. 

## Features

1. Cleaning and Preprocessing of text data (tokenization, stopword removal, padding sequences)

2. Model training using LSTM model
